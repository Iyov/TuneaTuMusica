CachaTuMusica

Documentación del proyecto — Actualizado: 18 de febrero de 2026

Resumen rápido

CachaTuMusica es una herramienta para limpiar y estandarizar metadatos musicales. Detecta y corrige tags desde múltiples fuentes: nombre de archivo, estructura de carpetas, fingerprinting (AcoustID/MusicBrainz) y, como último recurso, IA.

Principales cambios incluidos (2026-02-18)

  • Integración del motor AudioTagger con la GUI en gui.py: ejecución en hilo, polling de progreso y generación de reportes en logs/.
  • Mejoras en generación de reportes: CSV con utf-8-sig y Markdown opcional.
  • Implementación de los Casos A/B/C/D (reglas para derivar metadatos según nombre/tags/estructura).
  • Cadena de fallback: tags → fingerprint (AcoustID → MusicBrainz) → IA (OpenAI) con soporte de prueba mediante SANDBOX_TEST=1.
  • Nuevas opciones CLI: --dry-run, --no-backup, --format, --workers.

Cómo usar

CLI

python audio_tagger.py --dir "ruta/a/musica" --workers 4 --dry-run

Opciones importantes:

  • --dry-run: simula cambios.
  • --no-backup: no crea copias antes de escribir.
  • --format csv|md|both: formato del reporte.
  • --workers N: cantidad de hilos worker.

GUI

Ejecuta python gui.py para abrir la interfaz gráfica. La GUI ahora lanza el motor en un hilo y actualiza la barra de progreso consultando los resultados del AudioTagger. Al finalizar genera reportes en logs/.

Configuración

Editar config.json o usar variables de entorno:

{
  "acoustid_api_key": "TU_KEY",
  "openai_api_key": "TU_KEY_OPCIONAL",
  "ia_enabled": true
}

Instala fpcalc (Chromaprint) y añádelo a la variable PATH. Para pruebas sin servicios externos, exporta SANDBOX_TEST=1 (PowerShell: $env:SANDBOX_TEST='1').

Reportes y logs

Los reportes y logs se guardan en la carpeta logs/ con marcas temporales. El CSV se escribe con BOM para compatibilidad con Excel (utf-8-sig).

Ejemplos:

  • logs/log_2026-02-18_17-38-53.csv
  • logs/reporte_2026-02-18_17-38-53.md

Publicar en GitHub Pages

Al tener el index.html en la raíz del repositorio, la publicación es directa:

git add index.html css/ js/
git commit -m "docs: actualizar index.html en la raíz"
git push origin main

En la configuración de GitHub Pages (Settings > Pages), asegúrate de que la fuente sea la rama main y la carpeta / (root).

Notas sobre IA y límites

  • Las llamadas a OpenAI pueden generar errores 429 (rate limit). Se recomienda probar primero con SANDBOX_TEST=1.
  • El uso de IA tiene coste por tokens; monitorizar la cuenta si se procesa gran volumen.
