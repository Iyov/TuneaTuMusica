La Inteligencia detrás de CachaTuMusica

No es magia, es ingeniería. Clasificamos cada archivo en uno de estos 4 estados para aplicar la solución perfecta.

🟢 Caso A

Ruta ➝ Tags

El nombre del archivo es correcto pero los tags internos están vacíos.

Ej: "01 - Intro.mp3" tiene la info, el tag no.

🔵 Caso B

Tags ➝ Nombre

Los tags internos son correctos pero el nombre del archivo es un caos.

Ej: "descarga_123.mp3" con tags perfectos.

🟡 Caso C

Descubrimiento

Sin nombre ni tags. Activamos Fingerprinting (AcoustID) o IA.

Ej: "audio1.mp3" sin ninguna información.

⚪ Caso D

Estado Perfecto

Nombre y Tags están sincronizados y son correctos.

No requiere cambios. ¡Validado!

🚀 Comenzar Ahora

1. Descargar el Proyecto

Clona el repositorio oficial desde GitHub para obtener la última versión:

git clone https://github.com/Iyov/CachaTuMusica.git
cd CachaTuMusica

2. Instalar Dependencias

Asegúrate de tener Python instalado y ejecuta este comando para instalar las librerías necesarias:

pip install -r requirements.txt

3. Ejecución Local

Tienes dos formas de usar CachaTuMusica dependiendo de tu preferencia:

💻 Modo Terminal (CLI)

Ideal para procesar miles de archivos rápidamente.

python audio_tagger.py --dir "tu/musica"

🖥️ Modo Visual (GUI)

La interfaz moderna para un control total e intuitivo.

python gui.py
